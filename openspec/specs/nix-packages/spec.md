# nix-packages Specification

## Purpose
Flake package outputs, crane build, overlay, extension bundles, version and metadata.

## Requirements

### Requirement: Flake exposes the wobook packages
The flake SHALL expose `packages.x86_64-linux.wobook`, `wobookd`, `wobook-fzf`, `extension-firefox`, `extension-chromium` and `default` (equal to `wobook`), built with crane from the workspace sources.

#### Scenario: Build the CLI
- **WHEN** `nix build .#wobook` runs
- **THEN** the result contains `bin/wobook` and `result/bin/wobook --version` prints the crate version

#### Scenario: Build the daemon
- **WHEN** `nix build .#wobookd` runs
- **THEN** the result contains `bin/wobookd` and no `bin/wobook`

#### Scenario: Default package
- **WHEN** `nix build` runs with no attribute
- **THEN** the result is identical to `nix build .#wobook`

### Requirement: Dependency artifacts are shared
Rust packages and checks SHALL reuse one crane `cargoArtifacts` derivation so a source-only change does not rebuild dependencies.

#### Scenario: Source change
- **WHEN** a file under `crates/wobook/src` changes and `nix build .#wobook` runs again
- **THEN** the dependency artifacts derivation is not rebuilt

### Requirement: fzf wrapper package carries its runtime tools
`packages.wobook-fzf` SHALL be a `writeShellApplication` of `contrib/wobook-fzf.sh` with `wobook`, `fzf`, `wl-clipboard`, `xdg-utils` and `coreutils` on its PATH and SHALL fail to build if shellcheck reports warnings.

#### Scenario: Wrapper runs without a user PATH
- **WHEN** `env -i result/bin/wobook-fzf` runs
- **THEN** it prints `Available Options : --select --open --add --edit` and exits 0

### Requirement: Browser extension bundles
`packages.extension-firefox` SHALL produce an unsigned `wobook-<version>.xpi` built from `extension/` with the Firefox manifest, and `packages.extension-chromium` SHALL produce an unpacked directory containing `manifest.json` loadable through "Load unpacked".

#### Scenario: Firefox bundle
- **WHEN** `nix build .#extension-firefox` runs
- **THEN** the result contains exactly one `.xpi` file whose zip listing includes `manifest.json`

#### Scenario: Chromium directory
- **WHEN** `nix build .#extension-chromium` runs
- **THEN** `result/manifest.json` exists and declares `manifest_version` 3

### Requirement: Overlay
`overlays.default` SHALL add `wobook`, `wobookd` and `wobook-fzf` to a nixpkgs instance.

#### Scenario: Overlay applied
- **WHEN** nixpkgs is imported with `overlays = [ wobook.overlays.default ]`
- **THEN** `pkgs.wobook` evaluates to the same derivation as `packages.x86_64-linux.wobook`

### Requirement: Version string includes the git revision
Built binaries SHALL report `<cargo version> (<git short rev>)`, with `dirty` or `unknown` when the revision is unavailable.

#### Scenario: Clean checkout
- **WHEN** the flake is built from a committed tree
- **THEN** `wobook --version` contains the 7-character short revision

### Requirement: Shell completions are shipped
`packages.wobook` SHALL install zsh, fish and bash completions generated by `wobook completions <shell>` under `share/zsh/site-functions/_wobook`, `share/fish/vendor_completions.d/wobook.fish` and `share/bash-completion/completions/wobook`.

#### Scenario: Completion files present
- **WHEN** `nix build .#wobook` runs
- **THEN** all three completion files exist in the result
